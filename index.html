我的AI Agent使用记录

本页面记录我日常学习、编程时使用的AI智能体（Agent）、用途与使用效果

1. 豆包Agent

用途：Python代码调试、知识点讲解、习题解析、网页文案生成

效果：快速定位代码报错，解释原理，缩短编程试错时间，辅助完成课程作业

2. GitHub Copilot Agent

用途：PyCharm内补全代码、写单元测试、注释生成、算法思路辅助

效果：提升编码速度，减少重复模板代码编写，适合AI方向实验代码开发

3. Perplexity Agent

用途：查阅AI论文、查找技术资料、检索最新技术信息

效果：自带引用来源，适合课程调研，快速整理文献摘要

4. NotebookLM Agent

用途：上传课件PDF，基于讲义问答、梳理复习提纲

效果：针对课程材料精准问答，整理复习要点，备考效率提升
